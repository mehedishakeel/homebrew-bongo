# Homebrew Bongo

Official Homebrew tap for [Bongo](https://github.com/mehedishakeel/Bongo) (Native Bangla Phonetic Keyboard for macOS).

## Installation

```bash
brew install --cask mehedishakeel/bongo/bongo
```

Or tap manually:

```bash
brew tap mehedishakeel/bongo
brew install --cask bongo
```
